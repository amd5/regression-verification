# Output Quality Scorecard

| Dimension | Gate |
| --- | --- |
| Requirement coverage | Every independent requirement has implementation and fresh evidence |
| Regression coverage | Every discovered verification entrypoint is registered or explicitly classified |
| UI/design coverage | Every surface maps implementation, design source, states, viewports, comparison mode, checks, and evidence profiles |
| Selection accuracy | Changed modules include transitive dependencies and required always-on checks |
| Result integrity | Non-passing statuses never become completion claims |
| Safety | Commands are argument arrays; risky profiles require project authority |
| Evidence | Reports identify selected modules, checks, timestamps, statuses, and blockers |
| Visual evidence integrity | Builds and component tests never substitute for required design-source, browser, screenshot, interaction, or real-device evidence |

The skill passes only when all dimensions are satisfied for the active task.
